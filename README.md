# Регистрация на ГТО

Сайт-форма для записи на сдачу нормативов ГТО. Заявки сохраняются в Google-таблицу
«Регистрация ГТО».

## Как это работает

- **Сайт** (`index.html`, `style.css`, `app.js`, эмблемы в `img/`) — статическая страница. Её можно разместить на GitHub Pages.
- **Бэкенд** (`apps-script/Code.gs`) — Google Apps Script, привязанный к таблице.

Форма на сайте собирается по самой таблице, поэтому код менять не нужно:

- **Даты сдачи** — это листы, название которых начинается с даты `дд.мм.гг`. Текст после даты показывается
  как подпись, например `23.11.26 (3-4 классы)` → «23.11.26 · 3-4 классы». Прошедшие даты скрываются.
- **Поля формы** — это заголовки первой строки в A:I, кроме «№». Если добавить столбец в этот диапазон, он сразу появится в форме. J:K отведены под аналитику.
- **Варианты выбора** берутся из раскрывающихся списков (Данные → Проверка данных) в столбце, начиная со
  2-й строки. Поддерживаются списки из перечисленных значений и из диапазона.
  Если у столбца «класс» нет списка, классы берутся из названия листа («3-4 классы» → 3 и 4).
  Если у поля нет списка, на сайте будет обычное поле ввода.
- **Информационное окно.** Когда участник выбирает дату, сначала открывается окно «Перед регистрацией»
  с инструкцией и двумя кнопками: «На сайте ГТО зарегистрирован» — открывает поля регистрации,
  «Не зарегистрирован на сайте ГТО» — открывает https://www.gto.ru/ в новой вкладке (окно на сайте остаётся,
  после регистрации на gto.ru можно вернуться и продолжить). Окно показывается один раз.
  Текст окна хранится в `rules.js` (по строке на абзац: «1.» — заголовок шага, «*» — пункт списка, строка с «!» в начале —
  красное предупреждение со знаком «!» вместо номера, ссылки кликабельны). Если заполнить лист «Правила» в таблице (столбец A, тот же формат), будет показан текст оттуда.
  Если на листе даты есть столбец «Правила», в нём отмечается согласие: галочка, если там флажки, иначе «Ознакомлен».
- Столбец, в названии которого есть «email» или «почта», становится полем «Электронная почта»
  (клавиатура с «@» на телефоне, проверка адреса, запись строчными буквами).
- Сайт проверяет: ФИО — минимум два слова, УИН — формат `00-00-0000000`, email — формат адреса,
  значение — один из вариантов списка.
- На экране «Вы записаны!» есть оранжевая плашка «НЕ ЗАБЫВАЕМ!» (справка с допуском, спортивная форма);
  её текст — `window.GTO_REMINDER` в `rules.js`.
- После отправки показывается экран «Вы записаны!» со всеми введёнными данными и кнопкой «Редактировать»:
  она возвращает к анкете с заполненными полями, и изменения сохраняются в ту же строку таблицы
  (даже если исправлен сам УИН).
- Заявка записывается на лист выбранной даты в столбцы с такими же заголовками, номер ставится автоматически.
  Пустые флажки и заранее проставленные номера в шаблоне не мешают: запись идёт в первую свободную строку.
- Если участник с таким УИН уже записан на эту дату, сайт показывает его текущие данные и спрашивает
  «Хотите отредактировать данные?». При согласии строка перезаписывается, № сохраняется.
- Лист «Основной» — шаблон: заявки в него не записываются; команда настройки аналитики добавляет сводку в J:K.

**Закрыть запись на дату:** откройте лист этой даты и выберите в меню таблицы **ГТО → Закрыть запись на эту дату**.
К названию листа добавится « [закрыто]», дата сразу пропадёт с сайта, а записи на листе останутся.
Открыть снова — **ГТО → Открыть запись на эту дату**. Ещё так работает скрытый лист или слово «закрыто» в названии.
Прошедшие даты скрываются сами.

**Добавить новую дату:** скопируйте лист «Основной» (или существующий лист с датой), переименуйте (например, `20.01.27 (5-6 классы)`)
и поменяйте варианты в раскрывающихся списках (классы, ступени, буквы). Сайт подхватит лист сразу.

## Настройка

1. **Подключить скрипт к таблице.** Откройте таблицу → *Расширения → Apps Script*.
   Замените содержимое `Code.gs` кодом из `apps-script/Code.gs` и сохраните.
2. **Опубликовать как веб-приложение.** Нажмите *Начать развертывание → Новое развертывание*,
   выберите тип «Веб-приложение» и укажите:
   - «Выполнять от имени»: **Я**;
   - «У кого есть доступ»: **Все**.

   Разрешите доступ к таблице и скопируйте URL вида `https://script.google.com/macros/s/.../exec`.
3. **Указать URL на сайте.** Вставьте этот адрес в `config.js` в поле `SCRIPT_URL`.
4. **Опубликовать сайт.** В репозитории на GitHub откройте *Settings → Pages* и выберите
   *Deploy from a branch*, ветку и папку `/ (root)`.

Чтобы добавить новую дату сдачи, создайте в таблице лист с таким же заголовком и названием
в формате `дд.мм.гг`. Дата сразу появится на сайте.

**Скорость загрузки.** Скрипт кэширует описание дат и полей на 5 минут; ручная правка таблицы сбрасывает кэш.
После переименования листов или смены раскрывающихся списков выберите в таблице меню **ГТО → Обновить данные на сайте**
(или подождите 5 минут). Сайт запоминает даты в браузере и при повторном открытии показывает их сразу,
а свежие данные подгружает в фоне.

> После изменения файлов сайта поменяйте число `?v=…` в ссылках на `style.css`, `*.js` и картинки в `index.html`
> (на любое новое), иначе телефоны могут ещё какое-то время показывать старую версию из кэша.

> После изменения `Code.gs` нужно обновить развертывание (*Управление развертываниями →
> Изменить → Новая версия*), иначе продолжит работать старый код.

## Аналитика по классам в J:K

После обновления `apps-script/Code.gs` в привязанном к таблице Apps Script:

1. Сохраните скрипт и обновите существующее развертывание веб-приложения до новой версии.
   Это обязательно: старая версия воспринимает заголовки аналитики как поля регистрации.
2. Перезагрузите таблицу и выберите **ГТО → Настроить аналитику по классам**
   (либо запустите `setupClassAnalytics` в редакторе скрипта).
3. Команда установит сводку на «Основном» и всех листах с датами, в том числе двух текущих.
   Если J:K содержат посторонние данные, установка остановится до изменений: сначала перенесите их.

В J:K выводятся «Класс» и «Количество зарегистрированных». Если есть отдельный столбец
«Буква», номер и буква объединяются: например, `3А`. Учитываются строки с заполненным
УИН, а если такого столбца нет — с заполненным ФИО. Пустые классы и строки шаблона
с заранее заполненными номерами/флажками не учитываются. На пустом листе видны только заголовки.

Формула пересчитывается при регистрации, редактировании и ручных изменениях таблицы.
При копировании «Основного» она ссылается на данные новой копии; повторно запускать команду
для каждой новой даты не нужно. Столбцы J:K должны оставаться свободными для результата формулы.
Команду можно запускать повторно. Записи участников в A:I она не изменяет.
