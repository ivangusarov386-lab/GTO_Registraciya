# Регистрация на ГТО

Сайт-форма для записи на сдачу нормативов ГТО. Заявки сохраняются в Google-таблицу
«Регистрация ГТО».

## Как это работает

- **Сайт** (`index.html`, `style.css`, `app.js`) — статическая страница. Её можно разместить на GitHub Pages.
- **Бэкенд** (`apps-script/Code.gs`) — Google Apps Script, привязанный к таблице.

Форма на сайте собирается по самой таблице, поэтому код менять не нужно:

- **Даты сдачи** — это листы, название которых начинается с даты `дд.мм.гг`. Текст после даты показывается
  как подпись, например `23.11.26 (3-4 классы)` → «23.11.26 · 3-4 классы». Прошедшие даты скрываются.
- **Поля формы** — это заголовки первой строки листа, кроме «№». Если добавить столбец, он сразу появится в форме.
- **Варианты выбора** берутся из раскрывающихся списков (Данные → Проверка данных) в столбце, начиная со
  2-й строки. Поддерживаются списки из перечисленных значений и из диапазона.
  Если у столбца «класс» нет списка, классы берутся из названия листа («3-4 классы» → 3 и 4).
  Если у поля нет списка, на сайте будет обычное поле ввода.
- **Информационное окно.** Когда участник выбирает дату, сначала открывается окно «Перед регистрацией»
  с инструкцией. Поля регистрации появляются только после нажатия «С правилами ознакомился»
  («Назад» снимает выбор даты). Окно показывается один раз — при смене даты повторно не появляется.
  Текст окна хранится в `rules.js` (по строке на абзац: «1.» — заголовок шага, «*» — пункт списка, строка с «!» в начале —
  красное предупреждение со знаком «!» вместо номера, ссылки кликабельны). Если заполнить лист «Правила» в таблице (столбец A, тот же формат), будет показан текст оттуда.
  Если на листе даты есть столбец «Правила», в нём отмечается согласие: галочка, если там флажки, иначе «Ознакомлен».
- Сайт проверяет: ФИО — минимум два слова, УИН — формат `00-00-0000000`, значение — одно из вариантов списка.
- Заявка записывается на лист выбранной даты в столбцы с такими же заголовками, номер ставится автоматически.
  Пустые флажки и заранее проставленные номера в шаблоне не мешают: запись идёт в первую свободную строку.
- Если участник с таким УИН уже записан на эту дату, сайт показывает его текущие данные и спрашивает
  «Хотите отредактировать данные?». При согласии строка перезаписывается, № сохраняется.
- Лист «Основной» — шаблон, скрипт его не изменяет.

**Добавить новую дату:** скопируйте лист «Основной» (или существующий лист с датой), переименуйте (например, `20.01.27 (5-6 классы)`)
и поменяйте варианты в раскрывающихся списках (классы, ступени, буквы). Сайт подхватит лист сразу.

## Настройка

1. **Подключить скрипт к таблице.** Откройте таблицу → *Расширения → Apps Script*.
   Замените содержимое `Code.gs` кодом из `apps-script/Code.gs` и сохраните.
2. **Опубликовать как веб-приложение.** Нажмите *Начать развертывание → Новое развертывание*,
   выберите тип «Веб-приложение» и укажите:
   - «Выполнять от имени»: **Я**;
   - «У кого есть доступ»: **Все**.

   Разрешите доступ к таблице и скопируйте URL вида `https://script.google.com/macros/s/.../exec`.
3. **Указать URL на сайте.** Вставьте этот адрес в `config.js` в поле `SCRIPT_URL`.
4. **Опубликовать сайт.** В репозитории на GitHub откройте *Settings → Pages* и выберите
   *Deploy from a branch*, ветку и папку `/ (root)`.

Чтобы добавить новую дату сдачи, создайте в таблице лист с таким же заголовком и названием
в формате `дд.мм.гг`. Дата сразу появится на сайте.

> После изменения `Code.gs` нужно обновить развертывание (*Управление развертываниями →
> Изменить → Новая версия*), иначе продолжит работать старый код.
