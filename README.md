# Регистрация на ГТО

Сайт-форма для записи на сдачу нормативов ГТО. Заявки сохраняются в Google-таблицу
«Регистрация ГТО».

## Как это работает

- **Сайт** (`index.html`, `style.css`, `app.js`) — статическая страница. Её можно разместить на GitHub Pages.
- **Бэкенд** (`apps-script/Code.gs`) — Google Apps Script, привязанный к таблице.
  - В списке дат на сайте показываются листы, названные датой в формате `дд.мм.гг` (например, `23.11.26`). Прошедшие даты автоматически скрываются.
  - Каждая заявка записывается на лист выбранной даты. В общий лист «Основной» участник попадает один раз (повторы по УИН не дублируются).
  - Повторно записаться на одну и ту же дату с тем же УИН нельзя.

Колонки таблицы: `№ | ФИО | УИН | Ступень | пол | класс | Буква`.

## Настройка

1. **Подключить скрипт к таблице.** Откройте таблицу → *Расширения → Apps Script*.
   Замените содержимое `Code.gs` кодом из `apps-script/Code.gs` и сохраните.
2. **Опубликовать как веб-приложение.** Нажмите *Начать развертывание → Новое развертывание*,
   выберите тип «Веб-приложение» и укажите:
   - «Выполнять от имени»: **Я**;
   - «У кого есть доступ»: **Все**.

   Разрешите доступ к таблице и скопируйте URL вида `https://script.google.com/macros/s/.../exec`.
3. **Указать URL на сайте.** Вставьте этот адрес в `config.js` в поле `SCRIPT_URL`.
4. **Опубликовать сайт.** В репозитории на GitHub откройте *Settings → Pages* и выберите
   *Deploy from a branch*, ветку и папку `/ (root)`.

Чтобы добавить новую дату сдачи, создайте в таблице лист с таким же заголовком и названием
в формате `дд.мм.гг`. Дата сразу появится на сайте.

> После изменения `Code.gs` нужно обновить развертывание (*Управление развертываниями →
> Изменить → Новая версия*), иначе продолжит работать старый код.
